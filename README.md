# Desenvolvimento Mobile

Repositório para registrar as aulas, exercícios e projetos desenvolvidos durante a disciplina de **Desenvolvimento Mobile**, parte do curso técnico em **Desenvolvimento de Sistemas** do SENAI.

## Sobre a disciplina

Nesta disciplina estou aprendendo os fundamentos do desenvolvimento de aplicativos móveis, desde os conceitos básicos até a criação de aplicações funcionais para Android e iOS.

## ⚛️ Tecnologias utilizadas

- **React Native** — framework para criação de apps mobile multiplataforma usando JavaScript e React.
- **JavaScript** — linguagem principal utilizada no desenvolvimento.
- **Expo** — ferramenta que facilita a criação, o teste e o build de projetos React Native.
- **Node.js e npm** — ambiente e gerenciador de pacotes usados para rodar os projetos.
- **Expo Go / Android Studio** — usados para testar e emular os aplicativos durante o desenvolvimento.

## Por que React Native?

O React Native foi escolhido pelo curso pois permite:

- Escrever uma única base de código em JavaScript e gerar aplicativos para Android e iOS.
- Reaproveitar conceitos de React, muito usado também no desenvolvimento web.
- Contar com uma comunidade grande e diversas bibliotecas prontas.
- Visualizar alterações em tempo real durante o desenvolvimento (Fast Refresh).

## ▶️ Como executar os projetos

Pré-requisitos: Node.js instalado e o app **Expo Go** no celular (ou um emulador Android/iOS configurado).

```bash
# Clonar o repositório
git clone https://github.com/seu-usuario/nome-do-repositorio.git

# Entrar na pasta do projeto desejado
cd projetos/nome-do-projeto

# Instalar as dependências
npm install

# Iniciar o projeto
npx expo start
```

Depois, basta escanear o QR Code exibido no terminal com o app Expo Go, ou rodar em um emulador.

# Mobile Development

Repository to keep track of the classes, exercises, and projects developed during the **Mobile Development** course, part of the **Systems Development** technical program at SENAI.

## About the course

In this course I'm learning the fundamentals of mobile app development, from basic concepts to building functional applications for Android and iOS.

## ⚛️ Technologies used

- **React Native** — framework for building cross-platform mobile apps using JavaScript and React.
- **JavaScript** — main language used in development.
- **Expo** — tool that makes it easier to create, test, and build React Native projects.
- **Node.js and npm** — environment and package manager used to run the projects.
- **Expo Go / Android Studio** — used to test and emulate the applications during development.

## Why React Native?

React Native was chosen for the course because it allows:

- Writing a single JavaScript codebase and generating applications for both Android and iOS.
- Reusing React concepts, which are also widely used in web development.
- Relying on a large community and a wide range of ready-to-use libraries.
- Seeing changes reflected in real time during development (Fast Refresh).

## ▶️ How to run the projects

Requirements: Node.js installed and the **Expo Go** app on your phone (or a configured Android/iOS emulator).

```bash
# Clone the repository
git clone https://github.com/your-username/repository-name.git

# Go into the desired project's folder
cd projects/project-name

# Install dependencies
npm install

# Start the project
npx expo start
```

Then just scan the QR Code shown in the terminal with the Expo Go app, or run it on an emulator.
